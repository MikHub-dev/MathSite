Initiation à l’axiomatisation

Objectif : comprendre ce qu’est un système axiomatique, manipuler des axiomes simples, construire des mini-théories cohérentes.

1Notion d’axiome

Un axiome est une règle de départ :

  • non démontrée,
  • admise comme vraie,
  • qui sert de base à toute la théorie.
Exemples accessibles
  • « Par deux points distincts passe une unique droite. »
  • « 0 est un nombre. »
  • « Tout nombre a un successeur. »

2Système axiomatique minimal

On montre aux élèves qu’un système axiomatique doit être :

✓

Cohérent

Pas de contradictions.

∀

Complet

Permet de démontrer les propriétés visées.

⊥

Indépendant

Aucun axiome inutile.

Un mini-système jouet : « Monde des points »

On peut illustrer avec un mini-système jouet. Axiomes :

  1. A1« Il existe au moins un point. »
  2. A2« Pour tous points A et B, distincts ou non, il existe une droite qui passe par A et B. »
  3. A3« Une droite contient au moins deux points distincts. »
Ce système permet déjà de démontrer
  • qu’il existe une droite,
  • qu’une droite contient au moins deux points,
  • qu’il existe au moins deux points distincts.

Preuve. Par A1, il existe un point P. Par A2 appliqué à A = B = P, il existe une droite d (première propriété). Par A3, d contient deux points distincts (deuxième propriété), donc il existe au moins deux points distincts (troisième propriété).

Remarque

Si A2 ne parlait que de points distincts, A1 ne suffirait pas à produire une première droite : un monde réduit à un seul point, sans aucune droite, vérifierait A1, A2 et A3 sans que les trois propriétés soient vraies. Le choix d’un énoncé précis des axiomes est justement ce que ce module fait travailler.

3Axiomes de Peano simplifiés

On peut introduire une version adaptée :

  1. P10 est un nombre.
  2. P2Chaque nombre a un successeur.
  3. P30 n’est le successeur d’aucun nombre.
  4. P4Deux nombres ayant le même successeur sont égaux.
  5. P5(Induction) Toute propriété vraie pour 0 et héréditaire est vraie pour tous les nombres.

Applications

  • définir l’addition par récurrence, avec deux règles qui en sont les définitions : a + 0 = a et a + S(b) = S(a + b),
  • démontrer par induction (P5) des propriétés qui n’en découlent pas directement : 0 + a = a, puis l’associativité et la commutativité de l’addition.
Exemple : démontrer que 0 + a = a par induction

Initialisation. 0 + 0 = 0, par la définition de l’addition avec a = 0.

Hérédité. Si 0 + a = a, alors 0 + S(a) = S(0 + a) = S(a), par la seconde règle puis l’hypothèse.

Par P5, 0 + a = a pour tout nombre a.

4Axiomes algébriques

Les élèves peuvent manipuler des structures :

G

Groupe

Fermeture, associativité, identité, inverse.

A

Anneau

Deux opérations, distributivité.

E

Espace vectoriel

Axiomes de combinaison linéaire.

Exemple : axiomes d’un groupe (G, ∗)

  1. G1a ∗ b ∈ G
  2. G2(a ∗ b) ∗ c = a ∗ (b ∗ c)
  3. G3il existe e tel que, pour tout a, e ∗ a = a ∗ e = a
  4. G4pour tout a, il existe a⁻¹ tel que a ∗ a⁻¹ = e

5Logique formelle intuitive

On introduit :

Les connecteurs

∧∨→¬

Les axiomes logiques

Par exemple, deux schémas d’axiomes :

  1. L1P → (Q → P)
  2. L2(P → (Q → R)) → ((P → Q) → (P → R))

Les règles d’inférence

Modus ponens, syllogisme, etc.

Exercice type

À partir des axiomes logiques et de modus ponens, démontrer :

P → P

Il faut les deux schémas L1 et L2 : L1 seul ne suffit pas.

Voir une démonstration
  1. 1(P → ((P → P) → P)) → ((P → (P → P)) → (P → P))
  2. 2P → ((P → P) → P)
  3. 3(P → (P → P)) → (P → P)
  4. 4P → (P → P)
  5. 5P → P

1 : L2 avec Q = P → P et R = P. 2 : L1 avec Q = P → P. 3 : modus ponens sur 2 et 1. 4 : L1 avec Q = P. 5 : modus ponens sur 4 et 3.

6Atelier : construire sa propre théorie

Tu peux proposer aux élèves de créer un mini-univers :

  1. choisir les objets (points, créatures, nombres, segments…),
  2. écrire 3 à 5 axiomes,
  3. dériver des théorèmes,
  4. vérifier cohérence et indépendance.

Exemple : le monde des « créatures »

  1. A1Chaque créature a un parent.
  2. A2Une créature ne peut être son propre parent.
  3. A3Si A est parent de B et B parent de C, alors A est ancêtre de C.
  4. A4Un parent d’une créature est l’un de ses ancêtres.
Théorème

Une créature a au moins un ancêtre.

Preuve. Soit C une créature. Par A1, elle a un parent B. Par A4, B est un ancêtre de C.

Cohérence et indépendance

Sans A4, A1 à A3 ne permettent pas de conclure : A3 ne parle que de grands-parents. Et A2 n’intervient pas dans cette preuve : est-il indépendant des autres ? Est-il nécessaire ? C’est le genre de question de l’atelier.

7Ce que l’axiomatisation apporte au lycée

  • renforce la rigueur,
  • clarifie la différence entre définition, axiome, théorème,
  • prépare à l’abstraction universitaire,
  • donne du pouvoir conceptuel (structures, logique, cohérence).
