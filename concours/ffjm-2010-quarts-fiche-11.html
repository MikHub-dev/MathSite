Coefficient 11FFJM - Jeux MathématiquesRésolution Complète

Énoncé du problème

Arthur a choisi pour son ordinateur un code à 6 chiffres tous différents ABCDEF. A est la moyenne de B et de CD (considéré comme un nombre de deux chiffres). AC est la moyenne de BE et de FE (considérés comme des nombres de deux chiffres).

Devinez la valeur de chaque lettre.

Aucun des nombres cités ne commence par un 0.

Réponse exacte :741069(A = 7, B = 4, C = 1, D = 0, E = 6, F = 9)

1. Niveau de classe & Catégorie officielle

Ce problème est extrait du Championnat International des Jeux Mathématiques et Logiques organisé par la FFJM (Fédération Française des Jeux Mathématiques).

Dans ces compétitions, les problèmes attribués au coefficient 11 correspondent aux catégories suivantes :

Catégories C1 & C2
C1 : classes de 6e et 5e (c’est le dernier problème de la catégorie).
C2 : classes de 4e et 3e.
Catégories L1, GP, L2 & HC
L1 : lycéens (Seconde, Première, Terminale).
GP : Grand Public ; L2 / HC : études supérieures et Haute Compétition.

Précisions sur la difficulté théorique

Même si le niveau scolaire formel rattaché au coefficient 11 est le niveau Collège (fin de 5e à 3e), la résolution de ce type d’épreuve repose sur la moyenne et l’écriture décimale plutôt que sur un programme de cours strictement scolaire.

2. Méthode de raisonnement pas à pas (Niveau Seconde)

C’est un excellent défi ! Ce problème s’appuie sur des concepts très simples : la moyenne, l’écriture décimale et un peu de bon sens.

1. Traduire

2A = B + 10C + D · 2(10A + C) = (10B + E) + (10F + E)

2. Le chiffre C

2A ≤ 18, donc CD = 2A − B < 18 : CD est un nombre de deux chiffres inférieur à 18, donc C = 1.

3. Résoudre

20A + 2 = 10(B + F) + 2E ⇒ E = 1 + 5k… on teste : A = 7, B = 4, D = 0 (4 + 10 = 14 = 2 × 7)
(46 + 96)/2 = 71 ✓ ⇒ code 741069

3. Résolution expliquée comme si tu étais en 5ème

C’est un super défi ! En 5ème, tu as déjà tous les outils nécessaires : la moyenne, les nombres à deux chiffres et un peu de logique !

Étape 1 : La première moyenne

A est la moyenne de B et de CD : A est un chiffre (au plus 9), donc B + CD ≤ 18. CD est donc un nombre entre 10 et 17 : C = 1.

Étape 2 : Essayer

A = 7 : B + CD = 14, par exemple B = 4 et CD = 10.

Étape 3 : La seconde moyenne

AC = 71 : BE + FE = 142. Avec B = 4 : 4E + FE = 142 ⇒ 46 + 96 = 142 (E = 6, F = 9) ✓.

Étape 4 : Conclure (la réponse finale)

Le code est 741069
Pourquoi c’est compréhensible dès la 5ème ?
  1. La moyenne : Tu sais que la moyenne de deux nombres est leur somme divisée par 2.
  2. Les nombres à deux chiffres : Tu sais que CD = 10 × C + D.
  3. La vérification : Tu sais contrôler que les six chiffres sont différents.

Méthode Claude

Voici ce que j’ajoute à la méthode :

Les points en plus par rapport à la « Méthode Gemini »
  • Une étape bien justifiée : 2E est pair et 20A + 2 − 10(B + F) se termine par 2, donc 2E se termine par 2 : E = 1 ou 6 ; comme C = 1, E = 6.
  • Contrôle par programme : les 151 200 codes à six chiffres différents ont été testés ; la solution est unique.
  • Le piège : oublier que D peut valoir 0 (seuls les premiers chiffres des nombres cités ne peuvent pas être nuls).
