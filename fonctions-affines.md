# Seconde — Fonctions affines

Notions : coefficient directeur, ordonnée à l'origine, détermination, signe, tableau de signes.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · rédaction
Énoncé : Pour f(x) = 3x − 2, donne le coefficient directeur et l'ordonnée à l'origine, puis calcule f(4).
Réponse attendue : 3 ; −2 ; f(4) = 10

### Modèle 1.2 — N1 - Application directe · 3 min · réponse numérique
Énoncé : Pour f(x) = −x + 5, calcule f(−2).
Réponse attendue : 7

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 6 min · rédaction
Énoncé : f est affine avec f(1) = 5 et f(3) = 11. Détermine l'expression de f.
Réponse attendue : a = (11 − 5)/2 = 3, b = 2 : f(x) = 3x + 2

### Modèle 2.2 — N2 - Entraînement · 5 min · rédaction
Énoncé : Étudie le signe de −2x + 6 selon les valeurs de x.
Réponse attendue : Positif pour x < 3, nul en 3, négatif pour x > 3

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 12 min · rédaction
Énoncé : Dresse le tableau de signes de (x − 1)(−2x + 4) et donne l'ensemble où l'expression est positive.
Réponse attendue : Positive sur [1 ; 2]

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Tarif A : 15 € d'abonnement puis 2 € par séance. Tarif B : 5 € par séance. À partir de combien de séances le tarif A est-il le moins cher ? Mets en équation.
Réponse attendue : 15 + 2n < 5n ⇔ n > 5 : à partir de 6 séances
