# 5e — Expressions littérales

Notions : substitution, simplification d'écriture, distributivité simple, test d'une égalité.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 2 min · réponse numérique
Énoncé : Calcule 3x + 2 pour x = 4.
Réponse attendue : 14

### Modèle 1.2 — N1 - Application directe · 2 min · rédaction
Énoncé : Écris plus simplement : 5 × a × 3.
Réponse attendue : 15a

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 4 min · rédaction
Énoncé : Développe : 4(x + 3).
Réponse attendue : 4x + 12

### Modèle 2.2 — N2 - Entraînement · 5 min · rédaction
Énoncé : Teste l'égalité 2x + 5 = 3x + 1 pour x = 4, puis pour x = 2. Conclus pour chaque valeur.
Réponse attendue : x = 4 : 13 = 13, vraie ; x = 2 : 9 ≠ 7, fausse

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 8 min · rédaction
Énoncé : Un rectangle a pour longueur L cm et pour largeur 3 cm. Écris une expression de son périmètre, développe-la, puis calcule le périmètre pour L = 7,5.
Réponse attendue : 2(L + 3) = 2L + 6 ; pour L = 7,5 : 21 cm

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Programme de calcul : choisir un nombre, ajouter 3, multiplier par 2, soustraire 6. Montre, en appelant x le nombre choisi, que le résultat est toujours le double du nombre choisi.
Réponse attendue : 2(x + 3) − 6 = 2x + 6 − 6 = 2x
