# 5e — Nombres relatifs

Notions : repérage sur une droite graduée, comparaison, addition et soustraction.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 2 min · rédaction
Énoncé : Range dans l'ordre croissant : −3 ; 2 ; −7 ; 0 ; 5.
Réponse attendue : −7 < −3 < 0 < 2 < 5

### Modèle 1.2 — N1 - Application directe · 2 min · réponse numérique
Énoncé : Calcule : (−8) + (+5).
Réponse attendue : −3

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 4 min · réponse numérique
Énoncé : Calcule : (−4) − (−9) + (−3).
Réponse attendue : 2 (soustraire −9 revient à ajouter 9)

### Modèle 2.2 — N2 - Entraînement · 4 min · réponse numérique
Énoncé : Sur une droite graduée, A a pour abscisse −3,5 et B a pour abscisse 2. Calcule la longueur AB.
Réponse attendue : 5,5

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 8 min · rédaction
Énoncé : Le matin, il fait −6 °C. La température augmente de 11 °C jusqu'à midi, puis baisse de 7 °C le soir. Quelle est la température le soir ? Justifie par un calcul en une ligne.
Réponse attendue : −6 + 11 − 7 = −2, soit −2 °C

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Trouve deux nombres relatifs dont la somme est −5 et dont la différence (le premier moins le second) est 3. Explique ta démarche.
Réponse attendue : −1 et −4 (−1 + (−4) = −5 et −1 − (−4) = 3)
