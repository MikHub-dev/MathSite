# 5e — Symétrie centrale

Notions : construction, propriétés de conservation, centre de symétrie, parallélogramme.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 2 min · réponse numérique
Énoncé : Dans un repère, A a pour coordonnées (3 ; 2). Donne les coordonnées de son symétrique par rapport à l'origine.
Réponse attendue : (−3 ; −2)

### Modèle 1.2 — N1 - Application directe · 2 min · QCM
Énoncé : Laquelle de ces figures n'a pas de centre de symétrie ? Choix : carré ; triangle équilatéral ; parallélogramme ; cercle.
Réponse attendue : triangle équilatéral

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 4 min · rédaction
Énoncé : [A'B'] est le symétrique de [AB] par rapport à O, et AB = 5 cm. Quelle est la longueur A'B' ? Cite la propriété utilisée.
Réponse attendue : 5 cm : la symétrie centrale conserve les longueurs

### Modèle 2.2 — N2 - Entraînement · 4 min · QCM
Énoncé : Le symétrique d'une droite (d) par rapport à un point O est : une droite perpendiculaire à (d) ; une droite parallèle à (d) ; un cercle ; un segment.
Réponse attendue : une droite parallèle à (d)

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 8 min · rédaction
Énoncé : Les diagonales [AC] et [BD] du quadrilatère ABCD ont le même milieu O. Quelle est la nature de ABCD ? Justifie avec une propriété.
Réponse attendue : Un parallélogramme : un quadrilatère dont les diagonales ont le même milieu est un parallélogramme

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Dans un repère, A(1 ; 4) et O(3 ; 1). Détermine les coordonnées de A', symétrique de A par rapport à O, en justifiant.
Réponse attendue : O est le milieu de [AA'] : A'(2×3 − 1 ; 2×1 − 4) = (5 ; −2)
