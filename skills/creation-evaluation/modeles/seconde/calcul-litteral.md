# Seconde — Calcul littéral

Notions : développer, factoriser, identités remarquables, démontrer une égalité.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · rédaction
Énoncé : Développe 3(2x − 5).
Réponse attendue : 6x − 15

### Modèle 1.2 — N1 - Application directe · 3 min · rédaction
Énoncé : Développe (x + 4)².
Réponse attendue : x² + 8x + 16

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 5 min · rédaction
Énoncé : Factorise x² − 9.
Réponse attendue : (x − 3)(x + 3)

### Modèle 2.2 — N2 - Entraînement · 6 min · rédaction
Énoncé : Développe et réduis (2x − 1)(x + 3).
Réponse attendue : 2x² + 5x − 3

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Factorise (x + 1)(2x − 3) − (x + 1)(x + 2) en faisant apparaître le facteur commun.
Réponse attendue : (x + 1)(x − 5)

### Modèle 3.2 — N3 - Approfondissement · 12 min · rédaction
Énoncé : Démontre que, pour tout entier n, (n + 1)² − n² est un nombre impair.
Réponse attendue : (n + 1)² − n² = 2n + 1, impair
