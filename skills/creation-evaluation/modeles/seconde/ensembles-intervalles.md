# Seconde — Ensembles de nombres et intervalles

Notions : ℕ, ℤ, 𝔻, ℚ, ℝ ; intervalles, intersection, réunion ; valeur absolue.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · QCM
Énoncé : Le plus petit ensemble contenant −12/4 est : ℕ ; ℤ ; 𝔻 ; ℚ.
Réponse attendue : ℤ (−12/4 = −3)

### Modèle 1.2 — N1 - Application directe · 3 min · rédaction
Énoncé : Écris l'ensemble des réels x tels que −2 < x ≤ 5 sous forme d'intervalle.
Réponse attendue : ]−2 ; 5]

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 6 min · rédaction
Énoncé : Détermine [−1 ; 4] ∩ ]2 ; 7] et [−1 ; 4] ∪ ]2 ; 7].
Réponse attendue : ]2 ; 4] et [−1 ; 7]

### Modèle 2.2 — N2 - Entraînement · 5 min · réponse numérique
Énoncé : Combien d'entiers relatifs appartiennent à l'intervalle [−3 ; 2[ ?
Réponse attendue : 5

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 12 min · rédaction
Énoncé : Démontre que 1/3 n'est pas un nombre décimal.
Réponse attendue : Si 1/3 = a/10ⁿ, alors 10ⁿ = 3a ; 3 diviserait 10ⁿ = 2ⁿ × 5ⁿ, impossible

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Résous |x − 2| ≤ 3 en interprétant la valeur absolue comme une distance, et donne l'ensemble des solutions.
Réponse attendue : La distance de x à 2 est au plus 3 : x ∈ [−1 ; 5]
