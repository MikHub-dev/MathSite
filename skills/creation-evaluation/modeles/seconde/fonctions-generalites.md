# Seconde — Fonctions : généralités

Notions : image, antécédent, courbe représentative, ensemble de définition.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · réponse numérique
Énoncé : Soit f(x) = 2x² − 3. Calcule f(−2).
Réponse attendue : 5

### Modèle 1.2 — N1 - Application directe · 3 min · réponse numérique
Énoncé : Soit g(x) = 3x + 1. Quel est l'antécédent de 10 par g ?
Réponse attendue : 3

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 5 min · rédaction
Énoncé : Soit f(x) = x² − 4. Détermine les antécédents de 5 par f.
Réponse attendue : x² = 9 : 3 et −3

### Modèle 2.2 — N2 - Entraînement · 5 min · rédaction
Énoncé : Le point A(2 ; 7) appartient-il à la courbe de f(x) = x³ − 1 ? Justifie.
Réponse attendue : Oui : f(2) = 8 − 1 = 7

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Donne l'ensemble de définition de f(x) = 1/(x − 3), puis celui de g(x) = √(x + 2), en justifiant.
Réponse attendue : ℝ \ {3} (x − 3 ≠ 0) ; [−2 ; +∞[ (x + 2 ≥ 0)

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : L'aire d'un carré de côté c est A(c) = c². Calcule A(1,5), puis détermine le côté d'un carré d'aire 49 cm² en tenant compte du contexte.
Réponse attendue : 2,25 ; c = 7 cm (−7 exclu, une longueur est positive)
