# Seconde — Fonctions de référence

Notions : fonctions carré, inverse, racine carrée, cube : variations, comparaisons, équations et inéquations.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · rédaction
Énoncé : Sans calculatrice, compare 1,3² et 1,4² en citant une propriété de la fonction carré.
Réponse attendue : 1,3² < 1,4² : la fonction carré est croissante sur [0 ; +∞[

### Modèle 1.2 — N1 - Application directe · 3 min · réponse numérique
Énoncé : Calcule l'inverse de −0,25.
Réponse attendue : −4

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 5 min · rédaction
Énoncé : Résous x² = 16, puis x² < 9.
Réponse attendue : x = 4 ou x = −4 ; ]−3 ; 3[

### Modèle 2.2 — N2 - Entraînement · 5 min · rédaction
Énoncé : Compare 1/3,7 et 1/3,8 en citant une propriété de la fonction inverse.
Réponse attendue : 1/3,7 > 1/3,8 : la fonction inverse est décroissante sur ]0 ; +∞[

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Résous x² ≥ 4 et donne l'ensemble des solutions.
Réponse attendue : ]−∞ ; −2] ∪ [2 ; +∞[

### Modèle 3.2 — N3 - Approfondissement · 12 min · rédaction
Énoncé : On sait que −2 ≤ x ≤ 3. Donne le meilleur encadrement de x² en justifiant (attention au changement de signe).
Réponse attendue : 0 ≤ x² ≤ 9 : x² est minimal en 0, maximal en 3
