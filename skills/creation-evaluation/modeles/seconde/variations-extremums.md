# Seconde — Variations et extremums

Notions : tableau de variations, maximum, minimum, comparaison d'images, nombre de solutions.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · QCM
Énoncé : f(x) = −2x + 3 est : croissante sur ℝ ; décroissante sur ℝ ; constante.
Réponse attendue : décroissante sur ℝ (coefficient négatif)

### Modèle 1.2 — N1 - Application directe · 3 min · rédaction
Énoncé : f est croissante sur [−3 ; 1] et décroissante sur [1 ; 4], avec f(1) = 5. Quel est le maximum de f sur [−3 ; 4] et en quelle valeur est-il atteint ?
Réponse attendue : 5, atteint en 1

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 6 min · rédaction
Énoncé : Montre que f(x) = (x − 2)² + 1 admet un minimum sur ℝ ; donne sa valeur et où il est atteint.
Réponse attendue : (x − 2)² ≥ 0, donc f(x) ≥ 1 = f(2)

### Modèle 2.2 — N2 - Entraînement · 6 min · rédaction
Énoncé : f est croissante sur [−3 ; 1], décroissante sur [1 ; 4], avec f(−3) = 2, f(1) = 5, f(4) = −1. Combien de solutions a l'équation f(x) = 3 ? Justifie.
Réponse attendue : 2 : une sur ]−3 ; 1[, une sur ]1 ; 4[

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 12 min · rédaction
Énoncé : Montre que x² − 6x + 10 = (x − 3)² + 1, puis déduis-en le minimum de la fonction.
Réponse attendue : Développement ; minimum 1 atteint en 3

### Modèle 3.2 — N3 - Approfondissement · 8 min · rédaction
Énoncé : f est croissante sur [0 ; 1]. Compare f(0,5) et f(0,8) en justifiant.
Réponse attendue : 0,5 < 0,8 et f croissante donc f(0,5) ≤ f(0,8)
