# Seconde — Vecteurs

Notions : coordonnées, somme, norme, colinéarité, parallélogramme, alignement.

Exercices modèles originaux : ils servent de référence de niveau et de style. Ne pas les recopier ;
changer les nombres, les contextes et la formulation.

## N1 - Application directe

### Modèle 1.1 — N1 - Application directe · 3 min · rédaction
Énoncé : A(1 ; 2) et B(4 ; −1). Calcule les coordonnées du vecteur AB.
Réponse attendue : (3 ; −3)

### Modèle 1.2 — N1 - Application directe · 3 min · rédaction
Énoncé : u(2 ; −1) et v(−3 ; 4). Calcule les coordonnées de u + v.
Réponse attendue : (−1 ; 3)

## N2 - Entraînement

### Modèle 2.1 — N2 - Entraînement · 5 min · réponse numérique
Énoncé : Calcule la norme du vecteur u(3 ; −4).
Réponse attendue : 5

### Modèle 2.2 — N2 - Entraînement · 6 min · rédaction
Énoncé : Les vecteurs u(2 ; −3) et v(−4 ; 6) sont-ils colinéaires ? Justifie avec le déterminant.
Réponse attendue : 2 × 6 − (−3) × (−4) = 0 : oui

## N3 - Approfondissement

### Modèle 3.1 — N3 - Approfondissement · 12 min · rédaction
Énoncé : A(1 ; 1), B(4 ; 2), C(3 ; 5). Détermine D pour que ABCD soit un parallélogramme, en justifiant par une égalité de vecteurs.
Réponse attendue : AB = DC donne D(0 ; 4)

### Modèle 3.2 — N3 - Approfondissement · 10 min · rédaction
Énoncé : Les points A(0 ; 1), B(2 ; 5) et C(5 ; 11) sont-ils alignés ? Justifie.
Réponse attendue : AB(2 ; 4) et AC(5 ; 10) : déterminant nul, alignés
